# Shootstr - clean your following list the good old way

Shootstr is a browser-based Wolfenstein-style game that loads your Nostr follow graph and turns the profiles you follow into a playable target list.

## What this does

- Connects with Nostr relays (NIP-07 login or read-only npub input)
- Loads profiles from your follow list
- Classifies targets into waves based on recent activity recency
- Lets you run through local gameplay rounds and locally track unfollows
- Keeps data in the browser cache for faster reloads


## Requirements

- Modern browser with Nostr extension for publish mode (optional)
- Or paste your (or any other) npub for shits and giggles
